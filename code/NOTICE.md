# Third-party code

`kernel.py` is the FP8 kernel prefix from the appendix of
["Periodic Weak Spots: Phase Sensitivity from Chunked KV-Cache Compression"](https://arxiv.org/abs/2609.36322),
reproduced unmodified for the Figure 1 control experiment. Do not edit it:
the token positions asserted in `scripts/code_completion*.py` depend on it.
